Supported Backup Backends

rclone Supported - Recommended for most use cases. Handles SMB, NFS, S3, and 50+ cloud providers.
restic Supported - Best for encrypted, deduplicated backups with versioning.
kopia Supported - Modern backup with encryption, compression, and deduplication.
rsync Not supported - rsync backend exists but is not available for agent-based backups. Use rclone instead.

Backup tools (rclone, restic, kopia) are automatically downloaded to agents when they first connect. No manual installation required.

Agent Registration

To register a new agent, run the following command on the client machine: 

backer-agent register --server {{ server_url }}
