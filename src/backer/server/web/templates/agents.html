Windows Agent Setup

Install the Backer agent on Windows machines to backup:

1. Install Python (if not installed)

Download from python.org

2. Install Backer Agent

pip install backer

3. Register with this Server

backer agent register --server http://{{ request.host }}

4. Start the Agent

backer agent start

The agent will appear in this list once registered and running.
