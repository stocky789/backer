Windows Agent Setup

Install the Backer agent on Windows machines to enable backups:

1. Download the Installer

Download backer-agent-setup.exe

2. Run the Installer

Double-click the downloaded file and follow the installation wizard.

3. Connect to this Server

When the Backer Agent opens, enter this server address: 

http://{{ request.host }}

4. Click Connect

The agent will register with this server and appear in the list above.

Linux Agent Setup

Install the Backer agent on Linux machines:

Quick Install

curl -fsSL https://raw.githubusercontent.com/stocky789/backer/main/install.sh | sudo bash -s -- --agent

Or Manual Install

pip install backer
backer agent register --server http://{{ request.host }}
backer agent start

The agent will appear in the list above once registered and running.
